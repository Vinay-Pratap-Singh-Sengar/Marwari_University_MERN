# 🌐 What is Web Development?

Web Development is the process of building websites and web applications that run inside a web browser.

Examples:

- Google
- Facebook
- Amazon
- Instagram
- Netflix

All of these are web applications.

---

# 🏗 Client-Server Architecture

A web application works using the Client-Server model.

```
           Request
 Client ---------------------> Server
        <---------------------
             Response
```

### Example

When you open:

https://www.google.com

The browser sends a request to Google's server.

The server processes the request and sends the webpage back to your browser.

---

# 💻 What is a Client?

A Client is any device or application that requests information from a server.

Examples:

- Google Chrome
- Firefox
- Safari
- Microsoft Edge
- Mobile Apps

A client's job is to:

- Send Requests
- Receive Responses
- Display Data

---

# 🖥 What is a Server?

A Server is a computer or software that receives requests from clients and sends responses.

Responsibilities:

- Store Data
- Process Requests
- Authenticate Users
- Connect to Database
- Send Responses

Examples:

- Node.js Server
- Apache Server
- Nginx
- Express Server

---

# 🔄 Request Response Cycle

```
Browser
   │
   │ Request
   ▼
Server
   │
   │ Database Query
   ▼
MongoDB
   │
   │ Data
   ▼
Server
   │
   │ Response
   ▼
Browser
```

# ❓ Why Do Different Programming Languages Exist?

Every programming language is designed to solve specific problems.

Different languages have different strengths.

Examples:

| Language | Primary Use |
|-----------|-------------|
| C | Operating Systems |
| C++ | Game Development |
| Java | Enterprise Applications |
| Python | AI, ML, Automation |
| JavaScript | Web Development |
| PHP | Web Applications |
| Go | Cloud Applications |
| Rust | High Performance Systems |

No single language is best for every task.

The right language depends on the problem being solved.

---

# 🌍 What is Full Stack Development?

A Full Stack Developer builds both:

- Frontend
- Backend

along with the database.

Example:

```
Frontend
     │
React.js
     │
Express.js
     │
Node.js
     │
MongoDB
```

---

# 🚀 What is MERN Stack?

MERN stands for:

- MongoDB
- Express.js
- React.js
- Node.js

All four technologies use JavaScript.

This allows developers to build complete applications using a single programming language.

---

# 🧩 MERN Stack Architecture

```
React.js
     │
     ▼
Express.js
     │
     ▼
Node.js
     │
     ▼
MongoDB
```

---

# 📌 Role of Each Technology

## React.js

Used to build the User Interface.

Examples:

- Login Page
- Dashboard
- Product Page

---

## Node.js

Runs JavaScript on the server.

Responsible for:

- Business Logic
- API Development

---

## Express.js

Framework built on Node.js.

Provides:

- Routing
- Middleware
- REST APIs

---

## MongoDB

A NoSQL Database.

Stores:

- Users
- Products
- Orders
- Payments

# 💻 Software Required for MERN Stack Development

Before starting the MERN Stack course, install the following software on your computer.

| Software | Purpose | Download |
|----------|---------|----------|
| Visual Studio Code | Code Editor | https://code.visualstudio.com/ |
| Node.js (LTS Version) | JavaScript Runtime | https://nodejs.org/ |
| MongoDB Community Server | Database Server | https://www.mongodb.com/try/download/community |
| MongoDB Shell (mongosh) | Command Line Interface for MongoDB | https://www.mongodb.com/try/download/shell |
| MongoDB Compass | MongoDB GUI Tool | https://www.mongodb.com/products/tools/compass |
| Postman | API Testing Tool | https://www.postman.com/downloads/ |
| Git | Version Control System | https://git-scm.com/downloads |
| GitHub Account | Source Code Hosting | https://github.com/ |
| Google Chrome | Browser for Development & Testing | https://www.google.com/chrome/ |

---

# 📖 Purpose of Each Software

## 1. Visual Studio Code (VS Code)

VS Code is a lightweight and powerful source code editor used to write and manage code.

### Features

- Syntax Highlighting
- Auto Completion
- Extensions Support
- Integrated Terminal
- Git Integration
- Debugging Tools

---

## 2. Node.js

Node.js allows JavaScript to run outside the browser.

It is used to:

- Build Backend Applications
- Create REST APIs
- Handle File Systems
- Install Packages using npm

Example:

```bash
node app.js
```

---

## 3. MongoDB Community Server

MongoDB Community Server is the actual database server that stores application data.

Examples of stored data:

- Users
- Products
- Orders
- Payments
- Messages

Without the Community Server, MongoDB cannot store any data locally.

---

## 4. MongoDB Shell (mongosh)

MongoDB Shell is the command-line interface used to communicate with MongoDB.

Example commands:

```javascript
show dbs

use studentDB

show collections

db.students.find()
```

---

## 5. MongoDB Compass

MongoDB Compass is the graphical interface for MongoDB.

Using Compass, you can:

- Create Databases
- Create Collections
- Insert Documents
- Update Data
- Delete Records
- Execute Queries

No command-line knowledge is required for basic database management.

---

## 6. Postman

Postman is used to test REST APIs.

You can:

- Send GET Requests
- Send POST Requests
- Send PUT Requests
- Send DELETE Requests
- Test Authentication
- Test JSON Responses

Example:

```
GET http://localhost:5000/api/users
```

---

## 7. Git

Git is a Version Control System.

It helps developers:

- Track Changes
- Restore Previous Versions
- Work in Teams
- Manage Source Code

Common Commands:

```bash
git init

git add .

git commit -m "Initial Commit"

git push
```

---

## 8. GitHub

GitHub is a cloud platform used to store Git repositories.

Benefits:

- Backup Source Code
- Portfolio Building
- Team Collaboration
- Open Source Contributions
- Project Management

---

## 9. Google Chrome

Google Chrome is used for:

- Running Web Applications
- Inspecting HTML & CSS
- Debugging JavaScript
- Testing Responsive Design

Shortcut:

```
F12 → Open Developer Tools
```

# ✅ Verify Installation

Run these commands in the terminal.

Check Node.js Version

```bash
node -v
```

Check npm Version

```bash
npm -v
```

Check Git Version

```bash
git --version
```

Check MongoDB Shell

```bash
mongosh
```

If all commands execute successfully, your system is ready for MERN Stack Development.

# JavaScript Placement Training - Day 02

## 📖 Overview

This repository contains the source code and notes covered during **Day 02** of the JavaScript Placement Training series.

The focus of this session is to build a strong foundation in JavaScript by understanding variables, data types, scope, arrays, objects, JSON syntax, and commonly used array methods.

---

## 🎯 Learning Outcomes

After completing this session, students will be able to:

- Understand variable declaration using `var`, `let`, and `const`.
- Differentiate between Block Scope and Function Scope.
- Identify JavaScript Primitive Data Types.
- Use the `typeof` operator.
- Create and traverse arrays.
- Perform basic array operations.
- Create and traverse JavaScript objects.
- Understand the basic syntax of JSON.
- Apply these concepts to solve beginner-level programming problems.

## 📝 Practice Questions

1. Create an array of five student names.
2. Print all array elements using a `for` loop.
3. Print alternate elements of an array.
4. Print all array elements using a `for...of` loop.
5. Create an object containing your personal details.
6. Traverse an object using the `for...in` loop.
7. Perform `push()`, `pop()`, `shift()`, and `unshift()` on an array.
8. Demonstrate the difference between `var`, `let`, and `const`.
9. Write one example of Block Scope.
10. Write one example of Function Scope.
